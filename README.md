# Hearthside Music Lab

A standalone browser-based laboratory for composing and evaluating original procedural music. This project is separate from Hearthside.

## Principles
- No downloaded songs, samples, or remote audio assets.
- Written compositions: explicit notes, chords, tempo, phrasing, and arrangement.
- Deterministic playback: the same score produces the same musical sequence.
- Web Audio API synthesis; no server audio requests.
- Dialogue-friendly dynamics and restrained arrangements.

## Development
```bash
npm install
npm run dev
npm run build
```

## Current prototype
The first prototype uses a deliberately written score and a small additive/FM-inspired instrument engine. It is a composition and sound-design experiment, not a finished music product.
